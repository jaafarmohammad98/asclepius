Runs on this computer only. Files you pick are not sent anywhere else, and are deleted when the app stops. Thresholds are provisional, needs expert review.

Reading DUTCH report PDFs? Open the extractor page: it reads them in the browser and gives the dataset file (CSV) to load below.

Settings: the LLM that writes hypotheses

Hypotheses are written by an LLM you choose: Claude with your own Anthropic API key, or a model server on this computer (Ollama, llama-server, LM Studio), so nothing leaves it. Only group-level findings and library passages are sent, never a patient's record. The key is kept in , readable by you alone, and is never shown again.

    5. Hypotheses

    For each strong or suggestive finding, the LLM set in Settings proposes how it could come about, from passages of your paper library. Every quote is checked word for word against the paper it cites; one that is not found is removed. These are ideas to test, not conclusions.
